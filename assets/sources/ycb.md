# YCB objects

These assets are made from the [YCB Object and Model Set](https://www.ycbbenchmarks.com/) scans
(Calli, Walsman, Singh, Srinivasa, Abbeel and Dollar), released under
[CC BY 4.0](https://creativecommons.org/licenses/by/4.0/). The 16k Google scans were given collision
hulls and placement regions.
